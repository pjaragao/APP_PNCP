# Esquema da Base de Conhecimento

## O que é isto
Uma base de conhecimento sobre o APP que será desenvolvido integrado com a API do PNCP. o APP é para empresas que querem participar de licitações públicas, oferecendo suporte para automatização e inteligência de mercado.

## Como está Organizado
- `raw/` contém material de origem não processado. Nunca modifique esses arquivos.
- `wiki/` contém a wiki organizada. A IA mantém isso inteiramente.
- `outputs/` contém relatórios, respostas e análises gerados.

## Regras da Wiki
- Cada tópico recebe seu próprio arquivo .md em `wiki/`
- Cada arquivo da wiki começa com um resumo de um parágrafo
- Vincule tópicos relacionados entre si usando o formato `[[nome-do-topico]]`
- Mantenha um `INDEX.md` em `wiki/` que liste cada tópico com uma descrição de uma linha
- Quando novos materiais brutos forem adicionados, atualize os artigos relevantes da wiki
